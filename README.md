# HahnSoftware Internship Project
## Tools Used
### Backend
- Java
- Spring Boot
- Spring Security (JWT)
- Spring Data JPA
- Hibernate

### Frontend
- React
- Axios

### Database
- MySQL

## How to Run the Backend
1. Make sure Java (JDK 21) and Maven are installed.
2. 
2. Navigate to the backend directory:
   ```bash
   cd backend
   ```

3. Configure the database connection in `src/main/resources/application.properties`:
   - Update `spring.datasource.url` with your MySQL database URL
   - Update `spring.datasource.username` with your MySQL username
   - Update `spring.datasource.password` with your MySQL password
   - Update `app.jwt.secret` with a secure random secret (minimum 32 characters)

4. Create the MySQL database:
   ```sql
   CREATE DATABASE hahnsoftware_db;
   ```
5. Run the application:
   ```bash
   mvn spring-boot:run
   ```
   Backend will start on:
   ```
   http://localhost:8080
   ```
   Tables are automatically generated by Hibernate at application startup.
## How to Run the Frontend
1. Make sure Node.js and npm are installed.
2. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the application:
   ```bash
   npm start
   ```
   Frontend will be available at:
   ```
   http://localhost:3000
   ```
